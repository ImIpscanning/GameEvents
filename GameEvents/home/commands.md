# Commands

## Main Command:&#x20;

/ge

***

## Arguments

Arguments to be used in the main command

Meaning of table variables Null = empty <> = mandatory \[] = optional

{% tabs %}
{% tab title="Null" %}
Show Help Menu
{% endtab %}

{% tab title="configure <minigame>" %}
Start the configuration of the desired mini game

example:

/ge configure red
{% endtab %}

{% tab title="enable <minigame>" %}
Enables the ability to play the game (Requires prior configuration)

example:

/ge enable red
{% endtab %}

{% tab title="join <minigame>" %}
Join the desired mini game

example:

/ge join red
{% endtab %}

{% tab title="leave" %}
With this command you can exit the mini game (it requires you to have joined one before)

example:

/ge leave
{% endtab %}

{% tab title="start" %}
With this command you can start the desired mini game (requires previously activating the mini game)
{% endtab %}
{% endtabs %}
