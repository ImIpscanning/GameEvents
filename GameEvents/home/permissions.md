# Permissions

```
ge.help -> Receive the help command
ge.configure -> Configure games + Enable/Disable games
ge.start -> Start games (either with start <game> or startNext)
ge.stop -> Stop games (when a game stops so there is no winner)
ge.reload -> Reload the config
ge.join -> Join, leave games.
```
