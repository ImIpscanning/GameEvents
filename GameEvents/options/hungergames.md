# Hunger Games



***

## Options

```yaml
eliminationSound: ENTITY_LIGHTNING_BOLT_IMPACT 
loadouts: # All possible combinations of items that can appear in chests
# It has to be set up in game.
  1: empty

spawnLocations: # Where players appear. It's not an area like the other minigames, it's different points.
  location1: none
  location2: none

gameZone: # The entire area where the chests are to be regenerated
  corner1: empty
  corner2: empty
```

***

It is the only game without the max\_players and spawn\_location option, as there can be only as many&#x20;

players as there are spawn locations.

\
No one can get out of their spawn until it starts

\
Last Standing Wins
