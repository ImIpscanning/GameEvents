# TNT Tag



***

## Options

```yaml
explode_random_time: true -> Should the plugin choose a random time between min and max?
fastest_explode_time: 10 -> If random is not enabled, fastest time is always used
slowest_explode_time: 15

tnt_head_item: none -> The item in the tagger's head

tagged_sound: BLOCK_NOTE_BLOCK_GUITAR
explosion_sound: ENTITY_GENERIC_EXPLODE
```

Every time the time runs out, whoever is a tagger dies

\
Whenever the tager hits a non-tagger, it becomes

\
There is always 1 tagger for every 3 players (e.g. if there are 10 players there are 3 taggers)

\
Last Standing Wins
