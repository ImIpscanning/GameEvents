# Permissions

```
dchunkloader.place ->Allows placing chunk loaders
dchunkloader.use -> Allows using chunk loaders (right-click interaction)
dchunkloader.give ->Allows giving chunk loader items to players
dchunkloader.reload ->Allows reloading the plugin configuration
dchunkloader.admin -> Allows administrative actions (break others' loaders, etc.)
dchunkloader.info -> Allows viewing plugin information and statistics
dchunkloader.menu -> Allows opening the management GUI
dchunkloader.stats -> Shows chunk loader statistics on login
```
