# Commands

## Main Command:

/dchunkloader

***

## Arguments

Arguments to be used in the main command

Meaning of table variables Null = empty <> = mandatory \[] = optional

{% tabs %}
{% tab title="Null" %}
Show Help Menu
{% endtab %}

{% tab title="info" %}
View information about:

View the total number of chunk loaders set up

View the total number of active chunk loaders

View the total number of inactive chunk loaders

View the total number of holograms generated by the plugin

example:

/dchunkloader info
{% endtab %}

{% tab title="menu" %}
open a menu where you can request more information such as: how much percentage is loading from the server

example:

/dchunkloader menu
{% endtab %}

{% tab title="reload" %}
reload the plugin

example:

/dchunkloader reload
{% endtab %}

{% tab title="give" %}
give the charger block

example:

/dchunkloader give Dianelito basic 1\
/dchunkloader give \<player> \<block> \<level>
{% endtab %}
{% endtabs %}
