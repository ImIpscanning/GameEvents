![💰](https://cdn.jsdelivr.net/joypixels/assets/6.5/png/unicode/64/1f4b0.png) **Credit System (PlayerPoints System Used)​**

\


* 500 credits per kill: Players earn 500 credits for knocking someone off the arena.
* 300 credits per death: Players lose 300 credits if they fall into the void.
* Access restriction: A player needs at least 300 credits to play.
* Fully integrated with PlayerPoints for economy management.

\
\
\


![⚔️](https://cdn.jsdelivr.net/joypixels/assets/6.5/png/unicode/64/2694.png) **Combat Tag & Escape Penalty​**

\


* If a player is in combat (recently received knockback) and disconnects, they will be banned for 2 hours.
* Prevents players from logging out to avoid losing credits or matches.

\
\
\


![🔧](https://cdn.jsdelivr.net/joypixels/assets/6.5/png/unicode/64/1f527.png) **Command & Security Configuration​**

\


* / + TAB only shows relevant commands for players, hiding admin commands.
* Blocked commands like /plugins, /pl, /version, etc., to prevent server information leaks.
