#### Current Features​

​

* Customizable Configurations: Set up maps, kits, and loot systems with ease.​
* Regenerating Maps: Automatic map resets for continuous gameplay.​
* Flexible Settings: Tailor each game mode to suit your server’s needs.​
* Run multiple games at once, but only different types.
* Reward system: Give your players rewards through commands and messages.
* **NEW** Manual Mode: make an administrator able to control the game by giving orders (Green Light, Red Light, and Simon says)
